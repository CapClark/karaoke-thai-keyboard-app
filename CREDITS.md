# Credits

The code in this repository is MIT licensed (see [LICENSE](LICENSE)). The word data is
derived from the sources below; only word lists, spellings and counts are included, never
the original texts.

- **[PyThaiNLP](https://github.com/PyThaiNLP/pythainlp)** (Apache-2.0): Thai word list, the
  neural romanizer (`thai2rom`), the pronunciation model, word segmentation, and the lists
  of provinces, countries, first names and surnames.
- **Thai National Corpus (TNC)** word, word-pair and three-word counts, as distributed with
  PyThaiNLP: how often each word is used in formal writing.
- **[Wisesight Sentiment Corpus](https://github.com/PyThaiNLP/wisesight-sentiment)** (CC0):
  word counts from social-media posts.
- **[Wongnai Corpus](https://github.com/wongnai/wongnai-corpus)** (LGPL-3.0): word counts
  from restaurant reviews.

Hand-written spellings, chat words, phrases and names (`web/extra.js`,
`tools/names_hand.txt`) are part of this project.
