Karaoke Thai Keyboard

Type Thai by sound, using English letters: sawatdeekrap gives สวัสดีครับ, kinkhao gives กินข้าว.

Turn it on

  1. Open Settings → General → Keyboard → Keyboards.
  2. Tap Add New Keyboard… and choose Karaoke Thai.
  3. In any app, hold the 🌐 key and pick Karaoke Thai.
  4. Optional: tap Karaoke Thai in the keyboard list and turn on Allow Full Access for a light tap on each key. iOS requires it for haptics; the keyboard never goes online either way.

How to type

  • Space or Return types the first Thai guess.
  • Tap a guess to type that one. Swipe the bar sideways for more.
  • Tap the grey letters to keep them as English.
  • EN switches to plain English typing; ไทย switches back.
  • Words you pick come first next time.

Common questions

The word I want isn't first. Many Thai words sound alike in English letters (khao = เขา, เข้า, ข้าว). Pick the one you want; the keyboard remembers. Typing more of the sentence also helps: kinkhao gives กินข้าว.

It doesn't work with my iPad's physical keyboard. iOS doesn't pass physical-keyboard typing to third-party keyboards. Use the on-screen keyboard.

The keyboard doesn't appear in password fields. iOS always uses its own keyboard there.
