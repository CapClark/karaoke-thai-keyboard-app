**Description:**
Karaoke Thai Keyboard lets you type Thai by sound, using the English letters you already know.

Type "sawatdeekrap" and pick สวัสดีครับ. Type "kinkhao" and get กินข้าว. Type a whole sentence without spaces and the keyboard splits it into words for you.

• Spell it your way: kap, krap, khrap and krub all find ครับ. It understands the loose "karaoke" spellings Thais use in chat.
• Whole sentences: it uses the words around each word to pick the right one (kin khao → กินข้าว, not กินเขา).
• Fixes slips: swapped letters, a missed key or a near-sounding spelling still find the word.
• Names and places: nicknames, provinces, countries and brands are built in.
• Learns from you: words you pick move up next time.
• Private: everything runs on your device. The keyboard never connects to the internet.
• Feels native: light and dark mode, iPhone and iPad layouts, optional haptics.

Good for Thai speakers who type faster on an English layout, and for learners who know how a word sounds but not how to spell it.

How to turn it on: Settings → General → Keyboard → Keyboards → Add New Keyboard → Karaoke Thai. "Allow Full Access" is optional and only enables key haptics.

## App Review notes
This is a custom keyboard that types Thai from romanized ("karaoke") spellings. To test: open the app, follow the three steps on screen to add the keyboard, then type "sawatdeekrap" and press Space.

Full Access is optional. iOS only allows keyboard haptic feedback when Full Access is on, and haptics are the only thing the keyboard uses it for. The keyboard and its containing app make no network connections; all word matching runs on the device and nothing typed is stored or transmitted. Words the user picks are saved locally to rank them higher next time.
